# AgroKit — atualizações

**AgroKit** é uma ferramenta de **agricultura de precisão** para o QGIS: sistematização de áreas, linhas de plantio
e sulcação, cabeceiras e manobras, carreadores, análise de terreno e exportação de linhas para os monitores e pilotos
automáticos das máquinas (John Deere, Trimble, CNH, ISOXML e outros), com linha de comando ágil.

Este repositório guarda só o pacote compilado das versões, usado pela atualização automática do próprio plugin.
O `atualizacao.txt` é assinado pelo autor; o plugin só instala o zip se a assinatura e o SHA-256 conferirem.
O AgroKit só funciona com uma chave de licença emitida pelo autor (veja `LICENCA_AVALIACAO.txt` dentro do zip).
